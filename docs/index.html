WHAT IT DOES

Storage Scanner

Reads the whole Data volume once. Pause, resume or cancel at any point.

Large Files

Sort, filter and search files over 100 MB, 1 GB or 10 GB. Personal files are never auto-selected.

System Data

Shows what's inside System Data and marks which numbers are measured and which are estimated.

Developer Files

Docker, Xcode, Homebrew, npm, pnpm, pip, Hugging Face and LM Studio caches.

Safe Deletion

Protected paths are blocked and files in use are skipped. High-risk items need you to type DELETE.

Verify & Log

After each operation SOLID checks the result, logs it, and compares free space before and after.

HOW IT MEASURES

Walkfts(3), physical. Symlinks are never followed and the scan stays on one volume.
SizeAllocated blocks, the same as du. A sparse 228 GB disk image counts as the 22 GB it actually uses.
DuplicatesHard links are counted once. Firmlinked paths are walked only once.
SnapshotsTime Machine and APFS snapshots are listed with tmutil and diskutil.
PrivacyNo network access, accounts or telemetry. Everything stays on your Mac.
